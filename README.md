# SUAVECITO — Sistema de Investigación Social

Sistema de Investigación sobre Influencia Social en la Decisión de Compra de Ropa para Recién Nacidos.

## Tecnologías
- Next.js (App Router, React, TypeScript)
- Tailwind CSS
- Supabase (PostgreSQL, Auth, Realtime)
- Recharts
- Zod, React Hook Form

## Configuración
Copia `.env.example` a `.env.local` e incluye tus credenciales de Supabase.

Para ejecutar localmente:
```bash
npm run dev
```
